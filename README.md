Description:

The Last Kilowatt Prototype shows basic functionality of the game mechanics as players will simply allocation energy to structures. This prototype will mainly demonstrate the database connection from Unity game to Firebase Database.

Instructions for Prototype Execution:

1. Download package & extract files
2. Initialize Database connection by referencing Package Name and Engine to Firebase Database
3. Check Database Location/Region
4. Enable Firebase Authentication
5. Import Unity package to scene in Unity
6. Run & Test for functionality

Data Saved:
Data saved includes email, username, level, score, and time registered. Email will be omitted to collection but will be saved via userId, and the rest is saved and can be viewed by developer or admin.

Data retrieved:
Data retrieved include username, level, and score for gameplay progression.
